# Welcome

This vault is a small example of a notes-first task workflow. Each note becomes one card, and every open checkbox in that note stays on its card.

Move a card between **Now**, **Later**, **Someday**, and **Unassigned** to organize the whole project. Use the Task Queue to put individual next actions from different notes in the order you want to tackle them.

## Start here

- [ ] Review the project notes
- [ ] Choose one next action
- [ ] Move this note's card to Now
