# Changelog

## 0.1.2
- Rename the dashboard's Overview tab to Board and label unassigned tasks as Inbox.
- Separate Inbox tasks from the Now, Later, and Someday planning lanes.
- Group hidden tasks by note, with controls to restore individual tasks or a whole note.
- Add an expandable task search and a customizable task queue background color.
- Clarify settings for excluded files, automatic queue additions, and saved data for missing tasks.

## 0.1.0
- Organize open Markdown checkboxes into one card per note across Now, Later, Someday, and Unassigned.
- Keep an individually ordered task queue alongside the note-based board.
- Complete tasks in Obsidian notes, customize lane colors, filter tasks, and hide cards from the board.
- No runtime dependencies, accounts, network requests, or telemetry.
